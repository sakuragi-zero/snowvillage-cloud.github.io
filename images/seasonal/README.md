# 季節バナー画像 (`images/seasonal/`)

トップページ (`index.html`) のヒーローエリアに重ねる、月替わりの生成画像を置く場所です。

## 命名規則

```
hero-YYYY-MM.jpg
```

例: 2026年8月分なら `hero-2026-08.jpg`

- 年月ごとに **使い切り**（使い回しなし）。新しい月になったら新しいファイルを追加する。
- 過去分のファイルは削除せず残しておいてOK（アーカイブ・差し替え確認用）。表示は常にその日の年月に一致するファイルのみ。
- 該当月のファイルが存在しない場合は、自動的に何も重ねず既存の雪結晶背景（デフォルト表示）にフォールバックする。エラーにはならない。

## 画像仕様の目安

- 形式: `.jpg`（写真調の生成画像を想定）。透過が必要な場合のみ `.png` も可（ファイル名の拡張子を変えた場合は `script.js` の `applySeasonalHero` 側の候補拡張子リストも要確認）。
- 推奨サイズ: 横 1920px 以上（ヒーローエリアが `100vh` のフル画面背景のため、大画面でも粗くならない解像度）。
- ファイルサイズ: 500KB 以下を目安に圧縮する（TinyPNG 等）。CIの `lint:images` チェックで超過時に警告が出ます。
- 構図: 中央〜下部にテキストパネル（ロゴ・見出し）が重なるため、画像の主役は上部〜余白部分に寄せる。

## 反映方法

1. 生成した画像を上記の命名規則で `images/seasonal/` に配置してPRを作成する。
2. `npm run check` （またはCI）でサイズ警告が出ないか確認する。
3. マージすると、対象月になった時点で自動的にトップページへ反映される（コード変更は不要）。
